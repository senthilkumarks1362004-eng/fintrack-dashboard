# FinTrack - SaaS Analytics Dashboard

Premium, production-ready analytics dashboard for SaaS founders to track revenue, users, MRR and churn.

![FinTrack Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![Tailwind](https://img.shields.io/badge/Tailwind_CSS-3.x-38BDF8) ![Chart.js](https://img.shields.io/badge/Chart.js-4.x-FF6384)

**Live Demo:** https://senthilkumarks1362004-eng.github.io/fintrack-dashboard/

## 🔥 Features
- 📊 4 Interactive Charts (Line, Bar, Doughnut, Area) - Chart.js
- 🌓 Dark / Light Mode with localStorage persistence
- 📑 Collapsible Sidebar with modern SaaS UI
- 🔍 Transactions Table: Live Search + Sortable Headers + Pagination
- 📱 Fully Responsive — Mobile, Tablet, Desktop
- ⚡ 95+ Lighthouse Score - No frameworks, pure performance

## 🛠️ Stack
- HTML5, Tailwind CSS (CDN), Vanilla JavaScript (ES6+)
- Chart.js for data visualization
- Inter Font, Glassmorphism UI

Advanced frontend skills: State management, data visualization, table logic, theme handling, responsive architecture without frameworks.
